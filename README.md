# آلة حاسبة بواجهة رسومية

آلة حاسبة مكتبية بسيطة بواجهة عربية/مرئية مبنية باستخدام **Tkinter**. تنفّذ العمليات الحسابية من الأزرار أو لوحة المفاتيح، وتقيّم التعبيرات عبر محلّل آمن مبني على شجرة البنية المجردة (AST) في بايثون، من دون استخدام `eval()`.

## المزايا

- واجهة رسومية تعرض التعبير والنتيجة، مع أزرار للأرقام والعمليات.
- العمليات الحسابية المدعومة في مقيّم التعبيرات: الجمع (`+`)، الطرح (`-`)، الضرب (`*` أو `×`)، القسمة (`/` أو `÷`)، القسمة الصحيحة (`//`)، باقي القسمة (`%`)، والأس (`**`). كما يدعم الإشارتين الموجبة والسالبة.
- إدخال التعبيرات من لوحة المفاتيح، بما في ذلك الأرقام والفاصلة العشرية والعمليات والأقواس. يعمل Enter للحساب، وBackspace للحذف، وEscape أو Delete للمسح.
- معالجة أخطاء الإدخال والحساب، مثل التعبير غير المكتمل والقسمة على صفر والنتائج غير المحدودة؛ تظهر `Error` على الشاشة عند تعذّر الحساب.
- يقيّد المقيّم طول التعبير وحجم الأس والنتيجة لتجنّب الحسابات الضخمة.

## المتطلبات

- Python 3.
- Tkinter، وهي مضمّنة عادةً مع توزيعات Python المكتبية. قد تحتاج إلى تثبيتها كحزمة منفصلة على بعض توزيعات Linux.
- لفتح الواجهة الرسومية، يلزم توفر بيئة سطح مكتب.
- ملف `Calculator.vbs` مخصّص لنظام Windows؛ يستخدم مسار Python مضبوطًا مع خيار احتياطي وفق إعدادات المشغّل. لا يعمل على macOS أو Linux.

## التشغيل

### الطريقة المباشرة — جميع الأنظمة التي يتوفر عليها Python وTkinter

ضع `calculator.py` في مجلد المشروع، وافتح موجّه الأوامر أو الطرفية في ذلك المجلد، ثم شغّل:

```bash
python calculator.py
```

إذا كان أمر Python على جهازك هو `python3`، استخدم:

```bash
python3 calculator.py
```

### عبر مشغّل Windows

على Windows، يمكنك تشغيل `Calculator.vbs` لبدء الآلة الحاسبة باستخدام إعداد مسار Python وخيار الرجوع المضمّنين في المشغّل. إذا لم يبدأ البرنامج، شغّله مباشرةً بالأمر `python calculator.py` وتأكد من تثبيت Python وTkinter.

## ملفات المشروع

- `calculator.py` — الواجهة الرسومية ومقيّم التعبيرات.
- `Calculator.vbs` — مشغّل اختياري خاص بـWindows.

## ملاحظات

المقيّم يقبل عمليات أكثر من الأزرار الظاهرة في الواجهة؛ يمكن إدخال الأقواس وبعض العمليات الإضافية عبر لوحة المفاتيح. التعبيرات تقتصر على الصيغ الحسابية التي يسمح بها المقيّم.
